1. PROJECT OVERVIEW
1.1 One-Line Summary
Build a machine learning surrogate model integrated with differential evolution optimization to determine the optimal crude blend and process configuration for the Dangote Refinery (650,000 bpd), maximizing high-value product yield and refinery margin using free, open-source data and tools.

1.2 Project Type
Primary: Portfolio project for data science / ML engineering job applications

Secondary: Methodology demonstration for Nigeria's refining sector

Tertiary: Open-source contribution to energy analytics in Africa

1.3 Target Audience for This Document
AI agents assisting with research, coding, or review

Potential collaborators

Mentors providing feedback

Future self (for continuity across sessions)

1.4 Success Criteria
Criterion	Minimum Viable	Impressive	Exceptional
Surrogate model R²	> 0.80	> 0.90	> 0.95
Margin improvement over baseline	> 5%	> 10%	> 15%
Deployment	Local notebook	Streamlit Cloud	CI/CD + live dashboard
Documentation	README	Blog post	Published article + video
Data sources integrated	3	5	7+
1.5 Explicit Non-Goals
This is NOT a proprietary Dangote project. No NDA data is used.

This is NOT a real-time trading or procurement system.

This is NOT a replacement for rigorous process simulation (Aspen HYSYS, etc.).

This is NOT claiming to reveal Dangote's actual operations.

3. PROBLEM FORMULATION
3.1 Business Problem (Plain Language)
The Dangote Refinery must decide:

Which crude oils to buy (from a global market of hundreds of grades)

In what proportions to blend them (the "crude diet")

How to configure its process units (temperatures, pressures, catalyst ratios)

How to maximize the output of high-value products (gasoline, diesel, jet fuel, petrochemicals)

The goal is to maximize refinery margin — the difference between the value of products sold and the cost of crude purchased — while respecting physical, operational, and safety constraints.

3.2 Mathematical Formulation
Objective Function:

text
Maximize: Σ (predicted_yield_i × product_price_i) − Σ (blend_ratio_j × crude_cost_j)
Where:

i indexes products (gasoline, diesel, jet, petrochemicals, others)

j indexes crude types in the blend

Decision Variables:

text
x_j = blend ratio of crude j (continuous, 0 ≤ x_j ≤ 1)
u_k = throughput of unit k (continuous, within capacity limits)
t_k = operating temperature of unit k (continuous, within design range)
c_k = catalyst ratio of unit k (continuous, within design range)
Constraints:

text
Σ x_j = 1                          (blend ratios sum to 1)
x_j ≥ 0                            (no negative ratios)
API_blend_min ≤ API_blend ≤ API_blend_max   (refinery design limits)
S_blend ≤ S_max                    (sulfur limit)
throughput_k ≤ capacity_k          (unit capacity limits)
T_min ≤ t_k ≤ T_max                (temperature limits)
C_min ≤ c_k ≤ C_max                (catalyst ratio limits)
Blend property calculation:

text
API_blend = Σ (x_j × API_j)
S_blend = Σ (x_j × S_j)
3.3 Simplifying Assumptions (For Portfolio Scope)
Assumption	Rationale	Impact if Relaxed
Single time period (steady-state)	Simplifies optimization	Would become dynamic optimization
Linear blending for API and sulfur	Standard industry approximation	Non-linear blending models exist
5–10 crude types in the slate	Keeps problem tractable	More crudes = higher-dimensional search
Product prices are exogenous	We don't model market impact	Would require market equilibrium model
No inventory or logistics constraints	Out of scope	Would add supply chain layer
Surrogate model replaces rigorous simulation	Core novelty	Would require Aspen HYSYS integration
